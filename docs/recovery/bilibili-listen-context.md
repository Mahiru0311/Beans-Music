# B 站听视频列表接线记录

2026-10-14。本次为 Beans/CiliCili 原生代码之间的接线，尚未完成 Xcode 编译和真机验收。

## 已写入

- `VideoEntryRoute` 持有进入详情时的列表快照，避免其他页面改变正在使用的顺序。首页、搜索、作者、合集、收藏、账号列表和相关推荐均接入。
- 详情的 `VideoListenQueueSession` 用入口快照保留当前条目前后的内容；当前条目替换为完整详情数据，并去重。
- 分 P 生成独立 CID 条目，不能仅按 BVID 去重。当前选中条目保留完整名称、时长、封面和作者。
- `CiliCiliVideoListenRequest` 将队列和顺序标志传给 Beans；明确入口即使只有一项也不替换为作者第 1 页。
- 默认听视频的启动路径与手动切换共用交接，重复状态刷新不重复启动音频。
- 音频交接后释放评论、作者和相关推荐的启动等待；使用独立 `externalAudioHandoff` 状态，避免等待不存在的视频首帧。
- Beans 按当前条目的真实索引创建队列和顺序状态；上一首与下一首使用同一个播放器。
- 异步完成的官方/剧集列表可以更新 Beans 队列，不重建 AVPlayer、不重置进度。歌曲身份、播放代次和预期队列共同验证；用户切歌或手动改队列后拒绝旧更新。
- 音视频互切时从 Beans 获取当前内容的媒体时间和播放意图，避免详情的本地播放器被移交后续播时间退回 0。

## 尚未完成

- 当前入口使用已加载列表快照；到达末尾后继续拉取主页/搜索/作者/合集的下一页尚未接回 Beans。
- CiliCili 已解析的音频流和预加载素材还未传给 Beans，Beans 仍会使用自己的播放解析。
- Beans 下一首后，CiliCili 仍显示此前进入的详情；双向切换详情、评论、字幕和播放历史同步尚需实现。
- B 站详情内的音质选择和睡眠计时器与 Beans 控件还未全部统一。
- PGC 专用播放路由的剧集状态仍需实测，不能据队列代码宣称全部番剧可播。

## 必须验收

1. 首页、搜索、作者不同排序、合集和收藏：进入中间条目，切听视频，再上一首/下一首，顺序应与入口一致。
2. 多 P 视频从 P2 进入，上一首是 P1，下一首是 P3，CID 不重复、不丢失。
3. 单条入口不意外混入作者首页；无列表的外链保留当前的后备加载行为。
4. 默认听视频设置下直接打开详情，应开始 Beans 音频；关闭自动播放时保持暂停。
5. 听到指定秒数再切看视频，应从同一位置恢复；先暂停再切换应保留暂停意图。
6. 慢网加载队列期间切另一首、切另一视频、追加或重排队列，旧请求不能覆盖新队列。
7. 异步官方/剧集列表更新不重新开始当前音频；用户修改后的队列不被覆盖。

新增 `BilibiliListenQueueTests` 和 `VideoEntryContextTests` 覆盖中间选择、去重、分 P、缺失条目、空值和快照独立性；Windows 仅运行语法检查，XCTest 尚未执行。
